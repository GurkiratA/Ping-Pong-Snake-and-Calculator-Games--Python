# Python Mini Games & Projects

A collection of beginner Python projects focused on building interactive programs and developing core programming skills.

## Projects

### 🧮 Calculator
A command-line calculator that allows users to perform basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division

**Skills:** Python, functions, user input, conditionals, loops

### 🐍 Snake Game
A classic Snake game built with Python's Turtle graphics library. The player controls the snake using the arrow keys, collects food to grow, and must avoid colliding with itself.

**Skills:** Python, Turtle graphics, functions, keyboard input, collision detection, game logic

### 🏓 Pong
A two-player Pong game developed using Pygame. Players control paddles using the keyboard while the program handles ball movement, paddle collisions, scoring, and game boundaries.

**Skills:** Python, Pygame, game loops, event handling, collision detection, coordinate-based movement

## What I Learned

These projects helped me strengthen my understanding of:
- Python programming fundamentals
- Functions and modular code
- Loops and conditional logic
- User input and event handling
- Collision detection and coordinate systems
- Building interactive programs from scratch
